# misty-code

Misty's Code page, set aside as its own module.

[Misty](https://github.com/misty-org/misty) is a desktop app where your AI agents work in Spaces. The Code page
was its editor for a project folder: CodeMirror with vim and your own nvim mappings, language servers, a database
browser for SQLite and Postgres, source control and review, project chats beside the editor, and live sessions
where people in a Space code together on branches cut from one commit.

Misty no longer ships the Code page, so its beta can focus on the rest. Everything the page needed lives here,
ready to plug back in.

## What's inside

| Folder | What it is |
| --- | --- |
| `src/features/agents/code/` | The page (`CodePage.tsx`), the editor's addons (vim, language servers, git, live), project search, sessions and the project chat column, the database browser (`db/`), source control (`git/`) and live sessions (`live/`) |
| `native/src-tauri/features/code/` | The Rust side: language servers (`lsp/`), databases (`db/`), live session worktrees (`live/`), nvim config and git text |
| `native/src-tauri/permissions/autogenerated/` | The Tauri permissions for its 30 commands |
| `integration/misty.patch` | The changes in Misty that took the page out, reversed |

The folders mirror Misty's own, so a file here goes back to the same path in Misty.

## Using it

misty-code isn't an app on its own. It runs inside Misty and reaches into it through Misty's `@/…` and relative
imports. [HOST.md](HOST.md) lists what it needs from Misty and how to plug it back in.
